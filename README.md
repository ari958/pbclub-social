# PB Club social media

Finished, ready-to-post Instagram media for @play.pbclub. Buffer pulls each file from its raw link at post time, so files must stay in place after they are scheduled.

Layout: media/YYYY-MM-DD/<date>_<slot>.<ext>

## PB Club AI game

`game/index.html` is the Black Friday "PB Club AI" spoof game: one self-contained file with no build step and no dependencies other than Google Fonts. Open it in a browser, or host it anywhere static (for example GitHub Pages). Play: pick a shot (Dink J, Drive K, Lob L, or Space to let the AI pick) when the ring around the ball closes; aim with the arrow keys or by tapping the robots' court.
